# RC Packing-Feasible Note

Contribution toward the open packing-feasible moving-POVM problem in [christophergardner-star/RC-Discovery](https://github.com/christophergardner-star/RC-Discovery).

See `theory/packing_feasible_moving_povm.md` for the full note.

**Summary.** A positive lower bound on the smallest singular value of the synthesis operator of the near-unit spectral sectors is necessary and sufficient (up to constants) for quantitative rounding of a POVM to a nearby repeatable measurement. The rank-1 case is fully elementary with explicit constants; higher rank follows the same polar-factor construction.

This repository exists because the GitHub integration used for the work is authenticated as Cruxy234 and does not have write access to the original RC-Discovery repository. The note can be copied or submitted as a PR once access is available.
